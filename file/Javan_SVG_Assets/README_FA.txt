# بسته لوگو و SVG اپلیکیشن جوان

این بسته به‌عنوان مکمل طراحی رابط کاربری «جوان» آماده شده است و شامل موارد زیر است:

## محتویات
- `logos/svg/` : نسخه‌های وکتور لوگوی جوان
- `logos/png/` : خروجی PNG شفاف از لوگوها
- `icons/svg/` : آیکون‌های SVG مناسب رابط کاربری
- `icons/png/` : خروجی PNG آیکون‌ها
- `docs/brand_colors.txt` : رنگ‌های پیشنهادی برند

## نسخه‌های لوگو
1. `javan_logo_stacked_fullcolor.svg`
2. `javan_logo_horizontal_fullcolor.svg`
3. `javan_logo_horizontal_monodark.svg`
4. `javan_logo_horizontal_light.svg`
5. `javan_logo_icon.svg`
6. `javan_logo_icon_mono_dark.svg`
7. `javan_logo_icon_mono_light.svg`

## نکته مهم
- این فایل‌ها نسخهٔ وکتور بازطراحی‌شده بر اساس هویت بصری مشاهده‌شده در اسکرین‌شات‌ها هستند.
- این بسته شامل **SVG کاملِ تمام اسکرین‌ها** نیست؛ زیرا اسکرین‌های موجود از روی تصویر بازطراحی شده‌اند و خروجی فعلی آن‌ها رستری/تصویری است.
- اگر بخواهید، در مرحله بعد می‌توانم **هر اسکرین را جداگانه به فایل SVG/Editable UI** هم بازسازی کنم.
