پکیج کامل Assetهای JavanTicket

ساختار:
svg/brand       لوگوها و المان‌های برند
svg/admin       آیکون‌های منوی پنل ادمین
svg/common      آیکون‌های عمومی، هدر و اکشن‌ها
svg/categories  آیکون دسته‌بندی‌های سایت کاربر
svg/status      وضعیت‌های Success / Warning / Danger / Info / Active
png/reference   تصاویر کامل مرجع صفحات
png/event-images برش‌های تصویری مهم مثل نقشه ایران، Heroها و Seat Map

پیشنهاد استفاده:
frontend/admin/public/assets/
frontend/user/public/assets/

نکته:
اعداد، آمار، سفارش‌ها، درصدها، رویدادها و داده‌های داخل Screenshotها استاتیک طراحی هستند.
در پروژه واقعی باید از API دریافت شوند.
